## Estrutura do repositório

- `index.html` — a página do site
- `trilha.css` — identidade visual da trilha (tema “castelo”, comum a todos os sites)
- `trilha.js` — realce de código e botão “copiar”
- `img/` — sprites, ilustrações e ícones

## Publicar no GitHub Pages

1. Crie o repositório público `GameDev2D-P1-03` na conta `rclepf`.
2. Envie todo o conteúdo desta pasta para a raiz do repositório (o `index.html` precisa ficar na raiz).
3. Em **Settings → Pages**, escolha **Deploy from a branch → `main` / `(root)`** e salve.
4. Em 1 a 2 minutos o site fica disponível em `https://rclepf.github.io/GameDev2D-P1-03/`.

Para testar antes de publicar, basta abrir o `index.html` no navegador.
